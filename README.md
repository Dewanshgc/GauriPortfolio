# Dewansh Anirudh — Graphic design portfolio

A responsive, static portfolio site. Open `index.html` in a browser to preview it; there is no build step or package install.

## Personalize before sharing

- Replace `your.email@example.com` in `index.html` with your portfolio contact email.
- Review the name, location, biography and copyright line in `index.html`.
- The four book jackets are original CSS-rendered concept projects with fictional titles and authors. Replace them with your own cover artwork and project information before presenting the site as a portfolio of completed work. Cover markup is in `index.html`; project descriptions are in `script.js`; visual styling is in `styles.css`.
- Update the description and project category labels if you replace the concepts with client projects.

## Files

- `index.html` — page content and cover artwork markup
- `styles.css` — responsive layout, typography and cover illustrations
- `script.js` — category filters and project detail dialog
